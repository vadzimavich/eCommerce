# ♻️ eCommerce Recycled Plastic Platform

The final RS School Front-end 2025Q4 task.
It is an online store where you can buy products made from recycled plastic.
The project helps to understand how a real eCommerce platform works and emphasizes the importance of conscious consumption and caring for the environment.
A modular e-commerce frontend built with TypeScript, Webpack. This guide will help you set up and start working with the project locally — fast and efficiently.

## Project Features

- SPA (Single Page Application) without frameworks.
- Architecture (MVC).
- Product catalog with filtering and sorting.
- Viewing a product card and work with a shopping cart.
- Adaptive and accessible layout.
- ESLint, Prettier, Husky и Stylelint.
- Unit tests.

## Getting Started Locally

### Required software

- Currently version **Node.js: v22.11.0**

### Installation

To use the chat server application follow these steps:

- clone the repository.
- install the dependencies with npm i.
- start the local server using npm run serve.

```
git clone https://github.com/your-username/ecommerce.git
cd ecommerce
npm install
npm run serve
```

## Available Scripts

| Script                 | Description                                                              |
| ---------------------- | ------------------------------------------------------------------------ |
| `npm run build`        | Builds the project in default mode (production).                         |
| `npm run build:dev`    | Builds the project in development mode.                                  |
| `npm run build:prod`   | Builds the project in production mode.                                   |
| `npm run serve`        | Starts the development server with hot reload.                           |
| `npm run format`       | Automatically formats code using Prettier.                               |
| `npm run check-format` | Lists files with incorrect formatting.                                   |
| `npm run lint`         | Checks and auto-fixes ESLint issues in `.ts` files.                      |
| `npm run lint:css`     | Checks and auto-fixes CSS files using Stylelint.                         |
| `npm run lint:scss`    | Checks and auto-fixes SCSS files using Stylelint.                        |
| `npm run prepare`      | Installs Git hooks via Husky (automatically called after `npm install`). |
| `npm test`             | Runs a set of unit tests using Jest                                      |
| `npm test:related`     | Runs only the tests related to the changed files using Jest.             |
| `npm test:all`         | Executes a complete run of all unit tests in the project.                |
| `npm test:coverage`    | Runs tests and generates a report on code coverage by the tests.         |
